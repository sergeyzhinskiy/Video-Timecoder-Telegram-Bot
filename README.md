# Video-Timecoder-Telegram-Bot
Асинхронный Telegram-бот на базе **Telethon** для автоматической генерации структурированных тайм-кодов и саммари из видеороликов. Бот принимает прямые ссылки на видео или Excel-таблицы со списком ссылок, извлекает аудиодорожки, транскрибирует их с помощью **Deepgram** и формирует готовые отчеты через **YandexGPT**.
