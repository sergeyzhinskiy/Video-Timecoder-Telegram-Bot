#  Video Timecoder Telegram Bot

Асинхронный Telegram-бот на базе **Telethon** для автоматической генерации структурированных тайм-кодов и саммари из видеороликов с использованием нейросетей. Бот принимает прямые ссылки на видео или Excel-таблицы со списком ссылок, извлекает аудиодорожки, транскрибирует их с помощью **Deepgram** и формирует готовые отчеты через **YandexGPT**.

##  Ключевые возможности

*   **Мультиплатформенный захват видео:** Загрузка аудиодорожек с YouTube и других популярных платформ с помощью `yt-dlp`.
*   **Оптимизация под длинные видео:** Автоматическое разделение аудиофайлов длиннее 30 минут на части с помощью `FFmpeg` для стабильной обработки.
*   **Бесперебойная транскрибация (Key Rotation):** Автоматическая ротация пула API-ключей Deepgram в режиме реального времени при исчерпании лимитов или баланса на одном из них.
*   **Асинхронный пайплайн:** Полностью неблокирующий ввод-вывод (`asyncio`, `aiohttp`), позволяющий боту обрабатывать параллельные запросы.
*   **Пакетная обработка (Excel):** Возможность загрузить `.xlsx` файл со списком ссылок и получить обратно ZIP-архив с оформленными отчетами в формате `.docx`.

##  Зависимости и системные требования

Для полноценной работы скрипта в системе должны быть установлены **Python 3.10+** и мультимедийный пакет **FFmpeg**.

### 1. Установка системных утилит (FFmpeg)
Укажите в коде актуальные пути к исполняемым файлам `ffmpeg.exe` и `ffprobe.exe`. Для Windows пути по умолчанию в скрипте настроены на Chocolatey:
`c:/bot/factory/choc/tools/chocolateyInstall/lib/ffmpeg/tools/ffmpeg/bin/ffmpeg.exe`

### 2. Установка Python-библиотек
Установите внешние зависимости с помощью `pip`:
```bash
pip install telethon yt-dlp deepgram-sdk yandexcloud aiohttp openpyxl python-docx tenacity configparser
```

```ini

api_hash = abcdef1234567890abcdef1234567890
bot_token = 1234567890:ABCdefGhIJKlmNoPQRsTUVwXyZ

[Yandex]
yandexgpt_api = AQVNxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

[Deepgram]
# Можно указать неограниченное количество ключей для авторотации

```

##  Инструкция по использованию

1. Запустите бота:
   ```bash
   python bot.py
   ```
2. Откройте диалог с созданным ботом в Telegram и нажмите `/start`.

### Варианты взаимодействия:
*   **Одиночная ссылка:** Отправьте боту прямую URL-ссылку на видео. Бот пришлет готовые тайм-коды ответным сообщением (или текстовым файлом, если результат превысит 4000 символов).
*   **Пакетный режим:** 
    1. Отправьте боту файл `.xlsx` (ссылки должны находиться строго в **первом столбце**, начиная со второй строки).
    2. Отправьте команду `/timecod`.
    3. Бот обработает очередь и вернет файлы в виде `.zip` архива, содержащего `.docx` документы.
*   **Проверка статуса:** Команда `/status` выводит текущее состояние пула ключей Deepgram (общее количество, доступные и заблокированные из-за лимитов ключи).
		Команды бота
		
/start - приветственное сообщение и инструкция

/status - статус API ключей Deepgram

/timecod - запуск обработки загруженного Excel-файла

##  Логика обработки и промпт-инжиниринг

Бот форматирует тайм-коды через встроенный системный промпт для YandexGPT. Результат выводится в строгом иерархическом виде:

```text
00:00 – Введение
     # основная мысль 1
     # основная мысль 2
01:25 – Основная тема
     # основная мысль 1
```

При падении запросов к Deepgram из-за ошибок авторизации (401/403) или исчерпания баланса (402/429), класс `DeepgramKeyManager` налету переключает индекс на следующий валидный ключ, предотвращая падение запущенных пакетных задач.

Обработка ошибок - повторные попытки при сбоях

Валидация URL - проверка корректности ссылок

Ограничение длины - автоматическая отправка файлом при больших результатах

Кодировка UTF-8 - поддержка русского языка

## Примечания по использованию
1. Производительность: Обработка одного видео занимает 2-5 минут в зависимости от длины
2. Лимиты API: Рекомендуется иметь несколько Deepgram ключей для бесперебойной работы
3. Память: Бот автоматически очищает временные файлы, но следит за свободным местом
4. Форматирование: Тайм-коды генерируются в структурированном виде для удобного восприятия
